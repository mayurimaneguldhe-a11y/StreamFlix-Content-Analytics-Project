# StreamFlix Content Analytics

A 4-phase data analytics project built on a simulated streaming platform dataset 
(~980,000 records across subscribers, titles, watch history, ratings, reviews, 
and watchlists), using MySQL for data processing and Power BI for reporting.

## Project Phases

- **Phase 1 — Data Cleaning:** SQL-based data quality checks (referential 
  integrity, valid ranges, consistency validation) run against a 6-table 
  relational schema in MySQL.
- **Phase 2 — Exploratory Data Analysis:** SQL aggregation queries and 
  Python/matplotlib visualizations covering viewing trends, genre performance, 
  demographics, and device usage.
- **Phase 3 — KPI Calculation:** 12 core business metrics spanning engagement, 
  revenue (MRR/ARPU), churn, and content investment efficiency.
- **Phase 4 — Dashboard & Report:** A 5-page interactive Power BI dashboard 
  and a CEO-facing management summary report with findings, risks, 
  opportunities, and recommendations.

## Tech Stack
MySQL · Python (pandas, sqlalchemy) · Jupyter Notebook · Power BI
